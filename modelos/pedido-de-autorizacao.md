# Modelo: pedido de autorização (Samuel → Guilherme)

Agrupe vários pedidos numa mensagem só, numerados.

```
🔐 AUTORIZAÇÕES · <data> · <manhã/tarde>

1. <Cliente> · <o que precisa ser autorizado>
   Por quê: <contexto em 1–2 linhas>
   Opções: A) <...>  B) <...>
   Minha recomendação: <A/B> · <motivo>
   Pedido por: <bot>

2. ...

Responda com o número + a decisão (ex.: "1A, 2 ok, 3 não").
```
