# Checklist de revisão de texto

> Referência para o Revisor. Complementa o checklist de `equipe/revisor.md`, que tem a ordem oficial:
> regras do setor → informação → posicionamento e tom → texto → visual.

## 1. Escolha o modo de revisão
O modo define **quanto você pode mudar**.

| Modo | Quando | O que fazer |
|---|---|---|
| **A. Texto genérico** | Texto "de agência" ou com cara de IA, sem ponto de vista | Faça as 7 passadas abaixo. Pode reconstruir frases a partir dos fatos, mas **nunca** invente dados, casos ou resultados |
| **B. Texto com voz** | Tem a voz da cliente, mas está mal executado | Faça as 7 passadas **preservando** os argumentos, as palavras e a ênfase da cliente. Corrija o gancho enterrado, o vago, os vícios de IA e a estrutura |
| **C. Ajuste pontual** | "Arruma este gancho", "esta frase está boa?" | Não faça as passadas. Mude só o trecho pedido (e o mínimo ao redor), com uma linha de motivo por mudança e, se valer, uma alternativa. Problema sério em outro ponto: aponte em uma linha no fim, sem corrigir |

**Teste do "deixa como está":** para cada mudança, pergunte se ficou **melhor de forma clara** ou só
**diferente**. Se você não consegue dar um motivo, desfaça. O vocabulário da cliente é uma escolha
de voz: respeite.

## 2. Antes de começar
- [ ] Qual é o objetivo do conteúdo (briefing)?
- [ ] Quem é o público?
- [ ] Qual ação a pessoa deve tomar (CTA)?
- [ ] Leia uma vez inteira sem editar.

## 3. As 7 passadas

**1. Clareza**
- [ ] Toda frase é entendida na primeira leitura
- [ ] Nenhum termo técnico sem explicação
- [ ] Nenhuma frase tentando dizer coisas demais

**2. Voz e tom**
- [ ] O mesmo nível de formalidade do começo ao fim
- [ ] Soa como a cliente (compare com `posicionamento-e-tom.md` e `textos-aprovados.md`)
- [ ] Funciona lido em voz alta

**3. "E daí?"**
- [ ] Cada informação responde "por que isso importa para mim?"
- [ ] Nenhuma frase bonita e vazia

**4. Prova**
- [ ] Afirmações técnicas têm base (e a fonte, quando houver número)
- [ ] Nenhum superlativo sem fundamento ("o melhor", "o mais moderno")
- [ ] ⚠️ Médicos: nenhuma promessa ou garantia de resultado, nenhum depoimento ou antes e depois
  sem aprovação

**5. Especificidade**
- [ ] Palavras vagas trocadas por concretas
- [ ] Números, prazos e passos reais quando ajudam
- [ ] Enchimento removido

**6. Emoção na medida**
- [ ] A dor ou a dúvida do público soa real
- [ ] A emoção serve à mensagem, sem medo nem alarmismo (regra do CFM)

**7. Segurança para agir**
- [ ] As objeções principais têm resposta ("dói?", "demora?", "precisa de exame?")
- [ ] O próximo passo está claro
- [ ] ⛔ Nada de "garantia", "risco zero" ou "satisfação garantida" para médicos

## 4. Vícios de IA
Passe a lista de [`texto-sem-cara-de-ia.md`](texto-sem-cara-de-ia.md), principalmente:
- [ ] Nenhum "não é X, é Y" / "não só X, mas Y"
- [ ] Nenhuma lista "sem X, sem Y, sem Z"
- [ ] Nenhuma pergunta retórica respondida ("O resultado?") nem revelação com dois-pontos
- [ ] No máximo uma lista de três e um fragmento de efeito
- [ ] Nenhum travessão em legenda, slide ou capa
- [ ] Nenhuma abertura do tipo "Nos dias de hoje", "Você já parou para pensar"

## 5. Como devolver
Use o formato de `equipe/revisor.md` (✅ Aprovado · 🔁 Ajustes · ⛔ Bloqueado). Nos ajustes, diga
**o quê**, **onde** e **por quê**, e indique a passada ou o vício. Exemplo: "Slide 4, passada 4
(prova): 'o tratamento mais moderno do Brasil' é superlativo sem base e fere o CFM. Troque por uma
descrição do que o tratamento faz."
