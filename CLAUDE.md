# Straut Team: guia para o Claude

Responda sempre em português. Este repositório é a **memória compartilhada** entre os bots do OpenBot
e as conversas do Claude da Straut (Straut Brain · App e Straut Brain · Clientes).

- Antes de trabalhar, leia [`equipe/regras-gerais.md`](equipe/regras-gerais.md): as regras de
  sincronização, segurança e aprovação valem também para o Claude.
- **Straut Brain · Clientes** usa [`clientes/`](clientes/) como memória das clientes (substitui a pasta
  local `clientes/` do repositório `straut-brain`). Grave aqui o que descobrir sobre cada cliente.
- **Straut Brain · App** mantém [`integracoes/api-dos-bots.md`](integracoes/api-dos-bots.md) e
  [`straut/painel.md`](straut/painel.md) atualizados quando o painel mudar.
- As instruções dos bots ([`equipe/`](equipe/)) só mudam com aprovação do Guilherme.
- Os bots fazem o trabalho de rotina. O Claude é a ferramenta pessoal do Guilherme para o painel e para
  trabalhos especiais. Quando o Claude decidir algo que afete os bots, registre em
  [`gestao/decisoes.md`](gestao/decisoes.md).
